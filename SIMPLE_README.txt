===========================================================
       Shark Kitchen - Simple Setup Guide
===========================================================

Required Files:
├── shark_launcher.bat        ← Main launcher
└── SIMPLE_README.txt        ← This file

===========================================================
                 Requirements (Before Starting)
===========================================================

✅ Python 3.8 or later
   Download from: https://www.python.org/downloads/
   During install: Check "Add Python to PATH"

✅ Git
   Download from: https://git-scm.com/downloads

===========================================================
                    First Time Setup
===========================================================

1. Place files in the project folder "shark2"

2. Double-click: shark_launcher.bat

3. Choose option 1 (Install / Setup)
   Takes about 5-10 minutes
   Requires internet connection

4. Wait for: SUCCESS: Setup completed!

===========================================================
                        Daily Usage
===========================================================

Double-click: shark_launcher.bat

You will see these options:

1 - Install / Setup
   Press 1 then Enter
   Installs dependencies and creates database
   Requires internet connection

2 - Update from GitHub
   Press 2 then Enter
   Pulls latest updates from GitHub
   Requires internet connection

3 - Run Project
   Press 3 then Enter
   Starts the server
   Open browser at: http://127.0.0.1:8000

4 - Open Browser
   Press 4 then Enter
   Opens browser automatically

5 - Exit
   Press 5 then Enter
   Closes the launcher

===========================================================
                      Important Notes
===========================================================

✅ Recommended to update (option 2) before running

✅ Can work offline after installation
   Only needs internet for updates

✅ Do not move files after installation
   Launcher must be in project folder

✅ If you see "python is not recognized"
   Install Python from official website
   Make sure "Add Python to PATH" is checked

===========================================================
                    Troubleshooting
===========================================================

❌ Error: "python is not recognized"
   Install Python from official website
   Make sure "Add Python to PATH" is checked

❌ Error: "git is not recognized"
   Install Git from official website
   Restart computer after installation

❌ Error: "Setup failed"
   Check internet connection
   Make sure requirements.txt exists

❌ Error: "Run failed"
   Make sure you ran setup first
   Make sure installation completed
